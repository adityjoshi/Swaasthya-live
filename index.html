Swaasthya: A Modern Healthcare Management Ecosystem

Swaasthya is a comprehensive digital platform designed to modernize and streamline hospital operations.

It’s built with Go microservices, blockchain smart contracts for medical history, Kafka for real-time data streams, and a sleek Android app.

This isn’t just software — it's the foundation for the future of connected healthcare.

Blockchain-secured Health Records

This component utilizes Ethereum smart contracts to securely store hospital and patient records on-chain, ensuring immutability and transparency. Patients can control who has access to their medical history while institutions can trust the data's authenticity.

Backend System with Kafka, Redis & Go

The backbone of Swaasthya features a robust microservices architecture written in Golang. It leverages Kafka for real-time event streaming, Redis for fast in-memory data caching, and offers modularity for scaling each service independently.

View Backend Repo →

Android App with Firebase & Jetpack Compose

Built using Kotlin and Jetpack Compose, the Android client simplifies patient onboarding, appointment booking, and report tracking. Firebase integration ensures secure authentication and real-time sync between patients and hospitals.
